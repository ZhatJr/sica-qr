===================================================================
 SICA-QR | Instalacion de la base de datos en PostgreSQL
===================================================================

ARCHIVOS
  01_SICA_QR_estructura.sql    Crea las 17 tablas (el mismo script
                               del segundo avance, sin cambios).
  02_SICA_QR_datos_prueba.sql  Carga datos ficticios en las 17 tablas.

Se ejecutan EN ESE ORDEN: primero el 01, despues el 02.


-------------------------------------------------------------------
 PASO 0 - Instalar PostgreSQL (si no lo tienes)
-------------------------------------------------------------------

1. Entra a  postgresql.org/download/windows  y haz clic en
   "Download the installer". Elige la version 16 o 17 para Windows x86-64.
2. Ejecuta el instalador. Deja marcados todos los componentes
   (incluye pgAdmin 4).
3. Te pedira una contrasena para el usuario "postgres".
   ANOTALA: la usara el proyecto Java para conectarse.
4. Puerto: deja 5432. Lo demas, siguiente y finalizar.
5. Si al final aparece "Stack Builder", cancelalo. No hace falta.


-------------------------------------------------------------------
 PASO 1 - Crear la base de datos
-------------------------------------------------------------------

1. Abre pgAdmin 4 y escribe la contrasena del paso anterior.
2. En el panel izquierdo despliega:  Servers > PostgreSQL
3. Clic derecho en "Databases" > Create > Database...
4. Database:  sica_qr     (asi, en minusculas y con guion bajo)
5. Save.


-------------------------------------------------------------------
 PASO 2 - Crear las tablas
-------------------------------------------------------------------

1. Clic derecho sobre "sica_qr" > Query Tool.
2. En la barra del Query Tool, haz clic en el icono de carpeta
   (Open File) y elige  01_SICA_QR_estructura.sql
3. Presiona F5 (o el boton de play) para ejecutarlo.
4. Abajo debe decir:  "Query returned successfully".


-------------------------------------------------------------------
 PASO 3 - Cargar los datos de prueba
-------------------------------------------------------------------

1. En el mismo Query Tool, abre  02_SICA_QR_datos_prueba.sql
2. F5.
3. Abajo aparece una tabla con la cantidad de filas de cada tabla.
   Debe verse algo asi:

      rol                    4
      usuario                4
      estudiante            20
      matricula             20
      credencial            21
      registro_asistencia  200
      ... (17 filas en total)

   El numero de registros de asistencia puede variar un poco segun
   el dia en que lo ejecutes: se generan los ultimos 10 dias de
   clases antes de la fecha de hoy.


-------------------------------------------------------------------
 PASO 4 - Comprobar
-------------------------------------------------------------------

1. En el panel izquierdo: sica_qr > Schemas > public > Tables
2. Clic derecho en "Tables" > Refresh.
3. Deben aparecer las 17 tablas.
4. Para ver datos: clic derecho en una tabla (por ejemplo
   "estudiante") > View/Edit Data > All Rows.


-------------------------------------------------------------------
 USUARIOS DE PRUEBA (para cuando el sistema este listo)
-------------------------------------------------------------------

   Usuario      Contrasena      Rol
   admin        admin123        Administrador
   auxiliar     auxiliar123     Auxiliar de educacion
   docente      docente123      Docente o tutor
   direccion    direccion123    Direccion

Las contrasenas estan guardadas cifradas en la tabla "usuario".


-------------------------------------------------------------------
 SI ALGO FALLA
-------------------------------------------------------------------

"relation ... already exists"  o  "duplicate key value"
   Ya habias ejecutado el script antes. Borra la base y empieza
   de nuevo: clic derecho en sica_qr > Delete (Force) y vuelve
   al PASO 1.

"permission denied" o error al abrir el archivo
   Copia los .sql a una carpeta sin tildes ni espacios,
   por ejemplo  C:\sicaqr\  y vuelve a abrirlos desde ahi.
